# 页③ Xaero 地图转移（找回路径点）

单机世界传上服务器后，路径点和已探索地图不见了？
因为它们存在**单机世界的容器**里，服务器用的是**另一个容器**。
这一页就是把两者对接起来。

## 什么是容器

客户端 `xaero/minimap/` 下的每个文件夹 = 一个容器：

- `我的世界` = 你的单机世界（以单机世界名命名）
- `Multiplayer_<服务器地址>` = 你连的那个服务器

## 怎么用

| 字段 | 填什么 |
|---|---|
| 客户端目录 | 含 xaero 文件夹的目录，如 `..\.minecraft\versions\<版本名>` |
| 源容器 | 要搬走的，选单机世界名 |
| 目标容器 | 要搬到的，选 `Multiplayer_<服务器地址>`（可手输） |
| 服务器世界目录 | 可选，填服务器的 world 文件夹，用来自动读多世界ID |
| 多世界ID | 可选，纯数字，用于命名目标文件 |

1. 点「刷新容器列表」自动列出所有容器
2. 选好源 / 目标，按需勾选「路径点」「已探索地图」
3. 想更省事：填「服务器世界目录」→ 点「读取多世界ID」
4. 先点「扫描预览」看有多少数据 → 点「开始转移」

## 特点

- 路径点**自动去重**合并，不会重复
- 已探索地图只**补充**缺失区块，**不覆盖**目标已有
- 转移前自动备份目标文件，可还原
- 与 UUID 无关：路径点不看账号，只看容器
- 填了多世界ID：目标文件会自动命名为 `mw$<ID>_1.txt`，
  和你连服务器后客户端认的位置一致
- 「对齐到目标容器」：服务器换了ID时，一键把旧文件名改成新ID

注意：执行前请先退出游戏，否则会被游戏进程覆盖。

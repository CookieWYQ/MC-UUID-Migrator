# 工具简介

把「玩家A 的所有数据」整体转移成「玩家B 的」的绿色小工具。

## 原理

Minecraft 用 UUID 识别玩家：
数据文件以 UUID 命名，内容里也写 UUID。

工具把所有「写着 A」的地方改成 B：

- 文件名改名

- 文件内容逐字节替换

所以对任何版本、任何模组都通用：
背包 / 坐标 / 成就 / 女仆 / 区块实体…

## 三个功能页

| 页面         | 用途                   |
| ---------- | -------------------- |
| 单人存档       | 迁移自己电脑上的存档（本地）       |
| 多人服务器      | 迁移服务器世界（SFTP 远程）     |
| Xaero 地图转移 | 把单机世界的路径点/已探索地图搬到服务器 |

## 典型用途

- 正版存档 → 离线服务器（正版UUID → 离线UUID）

- 离线服务器 → 正版存档

- 单机世界传上服务器后，找回原来的路径点与地图

# 四个完整流程示例

## 示例A：正版单机存档 → 离线身份（本地）

1. 页① 选存档根目录
2. A=正版UUID，B=离线UUID
3. 开始迁移
4. 进游戏验证

## 示例B：服务器世界迁移（魂符场景）

1. 先停服（必须！）
2. 页② 填 SFTP 信息 → 测试连接
3. A=正版UUID，B=离线UUID（或用用户名一键替换）
4. 开始迁移 → 等待 下载镜像 / 替换 / 回传
5. 重启服务器 → 放魂符验证

## 示例C：找回路径点与地图（Xaero）

1. 退出游戏
2. 页③ 客户端目录 = 客户端里含 xaero 的目录
3. 刷新容器列表 → 源选单机世界名，目标选 Multiplayer_<服务器地址>
4. 勾选 路径点 + 已探索地图 → 扫描预览 → 开始转移
5. 进游戏查看路径点与地图

## 示例D：合并两个账号

B 是新号，要旧号 A 的全部数据

- 按示例A / B 跑一次
- B 原有数据会自动备份，不会丢

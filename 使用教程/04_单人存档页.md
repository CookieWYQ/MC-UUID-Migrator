# 页① 单人存档（本地目录）

处理自己电脑上的存档，全程不联网。

## 存档根目录（最关键）

填「存档所在的文件夹」，里面应有：
playerdata / stats / advancements / region / level.dat

## 怎么找到它

| 启动方式 | 位置 |
|---|---|
| 官方启动器(默认) | `%appdata%\.minecraft\saves\<存档名>` |
| 官方启动器(版本隔离) | `%appdata%\.minecraft\versions\<版本>\saves\<存档名>` |
| HMCL / PCL2 自定义目录 | 启动器设置里看「游戏目录」→ saves |

小技巧：按 Win+R 输入 %appdata% 回车即可进入。

## 填 A / B

来源UUID(A)、目标UUID(B) 同第3篇。

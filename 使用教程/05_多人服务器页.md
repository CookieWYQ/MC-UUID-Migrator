# 页② 多人服务器（SFTP 远程）

直接连服务器主机，远程迁移世界数据，无需下载整个服务器。

## 各字段

| 字段 | 填什么 |
|---|---|
| SFTP地址 | 主机商给的地址（在主机商面板里找） |
| 端口 | SFTP 端口（默认22，按主机商给的值） |
| 用户名 | 登录用户名 |
| 密码 | 可留空（免密服务器）；需要密码的留空会报认证失败 |
| 远端世界根目录 | 服务器世界文件夹路径，如 /world |
| 来源UUID(A)/目标UUID(B) | 同第3篇 |

## 远端根目录怎么找

世界文件夹标志：有 playerdata / region / entities / level.dat

- 在主机商面板「文件管理」里看根目录结构
- 或先用「测试连接」按钮验证路径

## 测试连接按钮

迁移前先点它确认能连上：

- 成功：显示 根目录可访问（N 个条目）
- 失败：显示具体原因（认证失败 / 超时 / 目录不存在）

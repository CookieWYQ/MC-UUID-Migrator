# 顶部公共区 与 底部按钮

## 顶部

用户名 + 方向下拉 + 一键替换

- 方向：正版→离线 / 离线→正版
- 填游戏名 → 点「一键替换」→ 自动算 UUID 并直接迁移

√ 记住密码

- 勾选：关闭程序后保存 SFTP 密码（混淆存储，非明文）
- 不勾：密码每次重填
- 地址 / 端口 / 用户名 / 根目录 总会自动保存，下次自动填好

## 底部（前两页共用）

| 按钮 | 作用 |
|---|---|
| 扫描 | 只读预览「文件名含A」的文件，不改任何东西 |
| 开始迁移 | 正式执行（先备份 → 改名 → 替换） |
| 取消 | 随时中止 |
| 进度条/日志 | 显示当前进度和每一步操作 |

Xaero 页用的是它自己的「扫描预览」「开始转移」两个按钮。

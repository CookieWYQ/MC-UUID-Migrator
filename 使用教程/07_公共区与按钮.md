# 顶部公共区 与 底部按钮

## 顶部

用户名 + 方向下拉 + 一键替换

- 方向：正版→离线 / 离线→正版
- 填游戏名 → 点「一键替换」→ 自动算 UUID 并直接迁移

右侧：`v1.2.0` 版本号 + 「检查更新」+「使用教程」

- **检查更新**：点一下即可查看是否有新版本
  - 检查顺序：Gitee 优先（国内更快）→ GitHub 兜底
  - 有新版：弹窗显示版本号 / 来源 / 大小 / 更新说明 → 点「是」自动下载、替换本程序并重启
  - 没有新版：提示「当前已是最新版本」
  - 程序**每次启动也会自动静默检查**：只有发现新版本才会提示，不会打扰
  - 弹窗选「否」= 跳过该版本，之后启动不再重复提示（仍可手动点「检查更新」查看）
- **使用教程**：打开内置的图文教程（10 篇）

## 多人服务器页的「记住密码」

- 勾选：关闭程序后保存 SFTP 密码（混淆存储，非明文）
- 不勾：密码每次重填
- 地址 / 端口 / 用户名 / 根目录 总会自动保存，下次自动填好

## 底部（前两页共用）

| 按钮 | 作用 |
|---|---|
| 扫描 | 只读预览「文件名含A」的文件，不改任何东西 |
| 开始迁移 | 正式执行（先备份 → 改名 → 替换） |
| 取消 | 随时中止 |
| 进度条/日志 | 显示当前进度和每一步操作；发现新版本也会记录在这里 |

Xaero 页用的是它自己的「扫描预览」「开始转移」两个按钮。

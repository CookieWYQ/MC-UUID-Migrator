# 顶部公共区 与 底部按钮

## 顶部

用户名 + 方向下拉 + 一键替换

- 方向：正版→离线 / 离线→正版
- 填游戏名 → 点「一键替换」→ 自动算 UUID 并直接迁移

右上角：「使用教程」按钮（打开内置的 10 篇图文教程）。

自动更新相关的入口都在 **「关于」页**，见下一节。

## 「关于」页

左侧是本工具图标，右侧是软件信息：

- 名称、版本号（形如 `v1.3.0`）
- 作者：CallMeACookieWYQ
- 许可：MIT
- 可点击链接：GitHub 仓库 / Gitee 发行版 / B站（作者主页）

下面「自动更新」区域：

- 状态行：当前版本 ｜ 更新源：Gitee（优先）→ GitHub ｜ 上次检查时间
- **检查更新**：手动检查一次
  - 有新版：显示版本号 / 来源 / 大小 / 发布时间的弹窗 → 点「是」自动下载、替换本程序并重启
  - 没有新版：提示「当前已是最新版本」
- **打开发布页**：浏览器打开最新版发布页（手动下载兜底）
- **使用教程**：与右上角按钮相同
- 下方文字区：显示检查顺序说明、发现的新版本与更新日志、下载/替换过程
- 程序**每次启动也会自动静默检查**：只有发现新版本才提示
- 弹窗选「否」= 跳过该版本，之后启动不再提示（仍可手动点「检查更新」）

## 多人服务器页的「记住密码」

- 勾选：关闭程序后保存 SFTP 密码（混淆存储，非明文）
- 不勾：密码每次重填
- 地址 / 端口 / 用户名 / 根目录 总会自动保存，下次自动填好

## 底部（前两页共用）

| 按钮 | 作用 |
|---|---|
| 扫描 | 只读预览「文件名含A」的文件，不改任何东西 |
| 开始迁移 | 正式执行（先备份 → 改名 → 替换） |
| 取消 | 随时中止 |
| 隐藏日志 / 显示日志 | 收起或展开下方的日志区；收起时腾出的空间全给上方分页 |
| 进度条/日志 | 显示当前进度和每一步操作；发现新版本也会记录在这里 |

说明：**进度条与状态栏始终显示**，不受「隐藏日志」影响；日志区默认是展开的。

Xaero 页用的是它自己的「扫描预览」「开始转移」两个按钮。
